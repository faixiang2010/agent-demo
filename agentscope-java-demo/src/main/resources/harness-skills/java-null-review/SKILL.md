# Java 空指针审查

1. 使用 read_file 读取本技能目录下的 references/rules.md。参考文件相对路径为 skills/java-null-review/references/rules.md。
2. 根据参考规则分析用户提供的代码，不修改文件。
3. 用中文回答，依次给出“风险”“安全写法”“学习要点”三个小节。
4. 回答开头写“【空指针审查技能】”，结尾带上参考文件里的规则编号。
5. 没有足够上下文时说明假设；不要编造已经运行过代码。
