# Spring AI Alibaba Demo 启动指南

## 环境要求

- JDK 17+（本项目基于 Spring Boot 3.5.3，必须 JDK 17 及以上）
- Maven 3.8+

## 快速启动

### 方式一：PowerShell（推荐）

```powershell
# 设置 JDK 17 环境变量（根据你的实际安装路径修改）
$env:JAVA_HOME = "D:\GreenSoft\java\jdk-17.0.14"

# 进入项目目录
cd D:\electron\spring-ai-alibaba-demo

# 启动项目
mvn spring-boot:run
```

### 方式二：CMD

```cmd
:: 设置 JDK 17 环境变量（根据你的实际安装路径修改）
set JAVA_HOME=D:\GreenSoft\java\jdk-17.0.14

:: 进入项目目录
cd /d D:\electron\spring-ai-alibaba-demo

:: 启动项目
mvn spring-boot:run
```

## 中文支持配置

项目已内置 UTF-8 编码配置，无需额外设置。相关配置如下：

| 配置项 | 位置 | 说明 |
|--------|------|------|
| `server.servlet.encoding.charset: UTF-8` | application.yml | HTTP 请求/响应强制 UTF-8 |
| `project.build.sourceEncoding: UTF-8` | pom.xml | Maven 编译源码 UTF-8 |
| `produces = "application/json;charset=UTF-8"` | Java 控制器 | 接口响应声明 UTF-8 |

如果终端中文仍然乱码，可按以下方式处理：

### PowerShell 终端编码

```powershell
# 设置控制台输出编码为 UTF-8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
chcp 65001
```

### CMD 终端编码

```cmd
:: 切换代码页为 UTF-8
chcp 65001
```

## 模型切换

项目同时支持 **DashScope（通义千问）** 和 **DeepSeek** 两个模型提供者，通过 `provider` 参数自由切换。

| 参数值 | 模型 | 默认 |
|--------|------|------|
| `dashscope` | 通义千问 qwen-plus | ✅ 是 |
| `deepseek` | DeepSeek deepseek-chat | 否 |

### 接口示例

```text
# 默认使用 DashScope
http://localhost:8080/ai/chat?message=你好

# 切换到 DeepSeek
http://localhost:8080/ai/chat?message=你好&provider=deepseek

# ReactAgent 智能体 - DashScope
http://localhost:8080/ai/agent?message=北京今天天气怎么样

# ReactAgent 智能体 - DeepSeek
http://localhost:8080/ai/agent?message=北京今天天气怎么样&provider=deepseek

# 查看可用模型列表
http://localhost:8080/ai/models
```

## API Key 配置

两个模型的 API Key 均已配置默认值，开箱即用。如需覆盖，支持环境变量和配置文件两种方式。

### 方式一：环境变量（推荐，不修改代码）

**PowerShell：**

```powershell
$env:AI_DASHSCOPE_API_KEY = "sk-your-dashscope-key"
$env:DEEPSEEK_API_KEY = "sk-your-deepseek-key"
mvn spring-boot:run
```

**CMD：**

```cmd
set AI_DASHSCOPE_API_KEY=sk-your-dashscope-key
set DEEPSEEK_API_KEY=sk-your-deepseek-key
mvn spring-boot:run
```

### 方式二：修改 application.yml

直接修改 `src/main/resources/application.yml` 中的默认值：

```yaml
spring:
  ai:
    dashscope:
      api-key: sk-your-dashscope-key
    openai:
      api-key: sk-your-deepseek-key
```
