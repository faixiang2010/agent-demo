# Electron 应用启动方式说明

## 项目概述

- **项目名称**: my-electron-app
- **版本**: 1.0.0
- **构建工具**: Electron Forge 7.11.2
- **Electron 版本**: ^23.1.3

## 项目结构

```
my-electron-app/
├── main.js          # 主进程入口文件
├── index.html       # 应用界面HTML文件
├── preload.js       # 预加载脚本
├── package.json     # 项目配置文件
└── forge.config.js  # Electron Forge 配置文件
```

## 启动命令

### 1. 开发模式启动（最常用）

```bash
cd my-electron-app
npm start
```

**说明**: 
- 执行 `electron-forge start` 命令
- 启动开发环境，支持热重载
- 适合开发和调试阶段使用

### 2. 打包应用

```bash
# 打包为未分发的格式
npm run package

# 打包为可分发的安装包（根据平台自动选择）
npm run make
```

**支持的打包格式**:
- **Windows**: Squirrel (.exe 安装程序)
- **macOS**: Zip (.zip) 和 Deb (.deb)
- **Linux**: Deb (.deb) 和 RPM (.rpm)

## 技术细节

### 主进程配置
- **入口文件**: `main.js`
- **窗口大小**: 800x600
- **加载页面**: `index.html`

### 安全特性 (Electron Fuses)
项目启用了以下安全配置：
- ✅ 禁用 RunAsNode 模式
- ✅ 启用 Cookie 加密
- ✅ 禁用 Node.js 环境变量选项
- ✅ 禁用 Node CLI 检查参数
- ✅ 启用嵌入式 Asar 完整性验证
- ✅ 仅从 Asar 加载应用

### 依赖项

**开发依赖**:
- @electron-forge/cli: 命令行工具
- @electron-forge/maker-*: 各平台打包工具
- @electron-forge/plugin-auto-unpack-natives: 自动解包原生模块
- @electron-forge/plugin-fuses: Fuse 配置插件

**运行时依赖**:
- electron-squirrel-startup: Windows Squirrel 启动处理

## 注意事项

1. 首次运行前请确保已执行 `npm install` 安装所有依赖
2. 开发模式下修改代码后会自动重新加载
3. 打包前请确保代码已通过测试
4. 不同操作系统会生成对应平台的安装包

## 故障排查

如果启动遇到问题，请检查：
- Node.js 版本是否兼容（建议 v16+）
- 是否已正确安装所有依赖：`npm install`
- 端口是否被占用
- 系统是否有足够的权限运行 Electron
