## 一、关键技术趋势（Key Technology Trends）

1. **1.0 稳定化潮**：主流框架相继进入 1.0/生产就绪——LangGraph（1.0.0 于 2025-10-17）、CrewAI（1.0.0 于 2025-10-20）、AG2（1.0.0 于 2026-07-27）、Microsoft Agent Framework（达 v1.0）。[S1][S2][S3][S4]
2. **协议标准化（MCP + A2A 分层收敛）**：MCP 管「智能体↔工具」、A2A 管「智能体↔智能体」，官方明确二者**互补非竞争**；被 CrewAI、AG2、SK/MAF、OpenAI Agents SDK、Microsoft Foundry 等内建支持。[A-C][S5][S10][S11]
3. **多智能体协作/编排成为核心竞争力**：从单体 Agent 转向 **orchestrator-worker（编排器-工作者）** 架构，主 Agent 规划并派发并行子 Agent，子 Agent 只回传 ~1,000–2,000 token 浓缩结论。[C]-S8
4. **记忆与上下文工程成为独立工程学科**：从 prompt engineering 演进为 **context engineering**；核心概念「context rot（上下文腐化）/ attention budget」；三大长时程技术 **compaction（压缩）/ structured note-taking（结构化笔记）/ sub-agent architectures**；配 just-in-time 检索与 progressive disclosure。[C]-S8
5. **架构「分层化」叙事成形**：出现 harness / framework / runtime / platform 的分层（如 LangChain 栈：Deep Agents harness → LangChain framework → LangGraph runtime → LangSmith platform）。[A]-S1
6. **从「对话编排」转向「运行时 + 工具 + 工作区」**：Sandbox agents（隔离工作区、可恢复会话）、durable execution（持久执行）、persistence、memory 成为标配。[A] 趋势4；[C]-S8
7. **评测与可观测性「一等公民化」**：LLM-as-judge 五维评分卡（factual accuracy / citation accuracy / completeness / source quality / tool efficiency）+ 终态评测（end-state evaluation）+ 生产级 tracing + OpenTelemetry GenAI 语义约定（含 Agent spans / MCP）。[C]-S8
8. **安全与治理体系化内建**：OWASP LLM Top 10（2025）之 LLM06 Excessive Agency 等风险清单 + OWASP Agentic Security 专项 + 企业身份（Entra）/ RBAC / VNet 隔离 / XPIA 跨提示注入缓解。[C]-S8
9. **厂商向垂直价值聚焦（定位重构）**：LlamaIndex 重心移向 LlamaParse 文档智能（判断「agents are the new consumers of documents」）；Semantic Kernel 更名为 Microsoft Agent Framework。[A]-S4、[A]-S5
10. **架构分叉成为显性事件**：AG2 与经典 AutoGen 正式分叉（AG2 v1.0 起协议驱动为顶层包，`pip install ag2` 不再含 `autogen`，**非 drop-in 升级**）。[A]-S2

## 二、市场数据（Market Data）

> 所有数据均含年份与出处；冲突口径见 §0.2-C1。

**市场规模与增速**
1. AI Agent 市场：2025 年 **76 亿美元** → 2026 年 **109 亿美元** → 2033 年 **1829 亿美元**，CAGR **49.6%**（2026–2033）；北美 2025 年占 **39.6%**。[B]-S6
2. AI Agent 市场：预计 2030 年达 **526.2 亿美元**，CAGR **46.3%**。（与上条口径不同，见 C1）[B]-S7

**企业采用与落地现状**
3. 生产落地率：仅 **11%** 组织已投产，**38%** 试点；**42%** 仍在制定战略、**35%** 无战略。[B]-S8
4. 失败预警：**Gartner 预测到 2027 年底 40% 的 agentic 项目将被取消**（经 Deloitte 交叉引用）。[B]-S8（次级来源）
5. 成本趋势：Token/推理成本两年内下降 **280 倍**（Stanford HAI、Deloitte 一致）。[B]-S8、[B]-S10
6. 采用速度参照：ChatGPT 达 **8 亿周活跃用户**（约占全球人口 10%）。[B]-S8

**企业采购与预算**
7. 企业 LLM 预算预计未来一年平均增长约 **75%**；创新预算占 LLM 支出比例从 **25% 降至 7%**；**37%** 企业使用 5+ 模型（去年 29%）。[B]-S9
8. 某高增长 SaaS 公司 **近 90% 代码由 AI 生成**（一年前 10–15%）。[B]-S9

**宏观投资与使用**
9. 2024 年美国私人 AI 投资 **1091 亿美元**（约中国 12 倍、英国 24 倍）；全球生成式 AI 私人投资 **339 亿美元**（同比 +18.7%）。[B]-S10
10. **78%** 组织在 2024 年使用了 AI（2023 年为 55%）；开放权重与闭源模型基准差距从 8% 缩小至 **1.7%**。[B]-S10

**开发/构建实践数据**
11. **43%** 组织在使用 LangGraph；涉及工具调用的 traces 占比 **0.5%（2023）→ 21.9%（2024）**；平均每 trace 步骤数 **2.8→7.7**。[B]-S11

**落地成效数据（案例级）**
12. Dynamiq × IBM：合同审查 **90 分钟→45 分钟**。[D]-S14
13. CrewAI 客户成效：Gelato **3,000+ 线索/月**；General Assembly 开发时间 **-90%**；DocuSign 首次触达 **+75%**；Piracanjuba 客服准确率 **95%**；某食品订购商 QA **74h→3h（-96%）**；官方称 **65% 财富 500 强**在用。[D]-S13

## 四、权威观点（Authoritative Views）

1. **多智能体显著优于单体（内部评测）**：Anthropic 称以 Claude Opus 4 为主、Claude Sonnet 4 为子 Agent 的多智能体系统，在其内部研究评测上**比单体 Opus 4 高 90.2%**；BrowseComp 上 token 用量单独解释 **80%** 性能方差（三因素合计 95%）。（**厂商内部评测，见 C5**）[C]-S8
2. **多智能体成本高昂**：Agent 交互约消耗 **4×** token，多智能体系统约 **15×** token，仅适合「任务价值高、可高度并行」场景。[C]-S8
3. **MCP = AI 的 USB-C**：Anthropic/官方定位 MCP 为「以单一协议取代碎片化集成」，实现 build once, integrate everywhere。[C]-S5
4. **MCP 与 A2A 互补非竞争**：官方明确「MCP 负责 agent-to-tool，A2A 负责 agent-to-agent」，A2A **不是**开发框架、**不是**工具调用协议、**不是** MCP 替代。[C]-S11
5. **上下文工程的指导原则**：Anthropic 主张「找到**尽可能小的高信号 token 集**」以最大化目标结果概率。[C]-S8
6. **评测理念转变**：Anthropic 认为多智能体无法用固定路径评测，需判断「是否达成正确结果且过程合理」。[C]-S8
7. **企业采购重心转向治理与规模化**：可观测性、成本核算、RBAC/审计、人类审批门、PII 脱敏、策略注入成为核心关注（CrewAI Control Plane、IBM agentic ROI 指南）。[D]-S13、[D]-S14
8. **协议即生态入口**：谁掌握协议（MCP/A2A/ACP）谁掌握生态入口，是「基础设施级」战场。[D]-S14

## 五、风险与挑战（Risks & Challenges）

1. **落地率低、预期过高**：仅 11% 投产、38% 试点，同时 Gartner 预警 **40% 项目 2027 年底前取消**——机会与泡沫并存。[B]-S8
2. **过度自主权（Excessive Agency）**：OWASP LLM Top 10（2025）单列 **LLM06 Excessive Agency**，另有提示注入、敏感信息泄露、系统提示泄露、无界消耗等风险。[C]-S8
3. **成本失控**：多智能体消费 ~15× token；即便成本大降，部分企业月账单仍达数千万美元。[C]-S8、[B]-S8
4. **上下文腐化与性能衰减**：token 增多导致召回能力下降（context rot），上下文是「回报递减的有限资源」。[C]-S8
5. **框架复杂度反噬**：Anthropic 警告重型框架抽象层可能掩盖底层 prompt/响应、增加调试难度、诱导不必要复杂度（**理念分歧，见 C4**）。[D]-S8
6. **厂商自报数据不可比**：CrewAI「5.76x」、Anthropic「90.2%」均为厂商内部/自述指标，缺乏第三方独立基准（**见 C5**）。[A]-S3、[C]-S8
7. **术语与生态分裂**：AutoGen vs AG2 分叉导致导入名、编排模型不兼容（非 drop-in），迁移成本高（**见 C2**）。[A]-S2
8. **治理与合规压力**：智能体泛滥（agent sprawl）、供应链/凭据安全、数据驻留、审计要求，推动 RBAC/隔离/身份治理成为必需。[D]-S13、[C]-S8
9. **来源可及性风险（调研方法层面）**：Gartner 官网、McKinsey、Menlo Ventures、Forbes、OpenAI Agents SDK/Google ADK 页面在本轮抓取中被反爬/超时/404 拦截，部分数字依赖次级来源交叉引用，存在时效与口径偏差风险（**见 C6**）。[B] 备注、[D] 备注
